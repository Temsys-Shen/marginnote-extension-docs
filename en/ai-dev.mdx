# AI-native services

This site provides [`llms.txt`](/llms.txt), [`llms-full.txt`](/llms-full.txt), [`skill.md`](/skill.md), and an MCP server so that AI tools can read the documentation as reference material for writing add-ons and templates.

## Connect to your AI tool

Click the small arrow next to the `Copy page` button at the top of any page to feed this documentation to ChatGPT, Claude, VS Code, or another AI tool. You can also install the site as a personal MCP server, or copy the page text and paste it into your AI tool.

# Generate code that follows the MN Rails conventions

You can certainly build an add-on step by step by following this documentation, but we recommend creating the project with [MN Rails](/en/mnrails) instead.

MN Rails generates a project layout that follows the MarginNote add-on conventions, ships a rich set of templates and scaffolds, and keeps AI-assisted development effective and consistent.
