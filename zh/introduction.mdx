# 准备定制你的Marginnote

在 Marginnote 5 之前（MN3、MN4），对 MN 的主要客制化手段为`经典插件`。而自 MN5 起，您可以通过新的`场景插件` 来进一步实现各种丰富的功能，并使用`Marginnote 场景模板` 将您的插件与各种资源、配置进行组合。

# Marginnote场景模板是什么

`Marginnote 场景模板`（后续会简称为 _MN 场景模板、MN模板、场景模板、模板_ 等）是 Marginnote 5 版本开始的一个新增功能，旨在帮助用户构建个人学习工作流并专注于每一个具体的环节和场景，并拓展每个场景的无限可能。

具体来说，每个模板由`模板配置`、`插件`与`样例`构成：

- 模板配置：工具与模式、顶部工具栏、卡片摘录与菜单、浮窗与浮球、插件启用、行为设置等。
- 插件：可选择启用`场景插件`和`经典插件`。插件可自定义行为与界面，实现更具个性化的配置。
- 样例：随模板附带的学习资料或者体验材料，应当能够帮助用户快速上手该模板。
- 除此之外，每个模板都**必须要有**`manifest.json` ，使得MN能够识别并显示该模板。

值得注意的是，以上三个均为可选项。也就是说，一个最小的场景模板可以没有任何实际内容，功能与沉浸模式相同。
