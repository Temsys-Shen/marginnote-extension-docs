插件面板需要获知 MN 内部发生的事情时，可以通过事件系统接收。事件必须先声明，而后才能在面板中收到来自 MN 的推送。

## 声明事件

在 `mnaddon.json` 中增加 `events` 字段：

```json mnaddon.json highlight={9} focus={9}
{
  "addonid": "mn.hello",
  "title": "你好世界",
  "version": "0.1.0",
  "author": "我",
  "marginnote_version_min": "4.5.0",
  "panel": "index.html",
  "icon": "hello.png",
  "events": ["excerpt", "comments"]
}
```

目前可以声明的事件如下：

- `excerpt`：创建摘录。
  - 返回`{noteid, opened}`。
  - 由于创建摘录时会以 mini 模式唤起所有接收符合条件的事件的面板，所以当唤起成功时 `opened` 为 true，失败或者已经打开面板时为 false
- `comments`：卡片批注有变化（包括折叠展开、新增、修改等）。
  - 返回`{noteid?,noteids}`。
  - 摘录卡片的批注变化时，脑图中的卡片和文档中的标注卡片均会包含在 `noteids` 里，但 `noteid` 仅为被修改的脑图中的卡片
- `practice`：作答纸（整卡截图批注）编辑器关闭。⚠️仅由当前插件打开的作答纸关闭时才可触发。
  - 返回 `{noteid, action, saved, commentId}`
- `synced`：同步合并完成。
  - 无返回值
- `undo`：撤销或重做。
  - 无返回值
- `imported`：卡片被批量添加进学习集。
  - 无返回值

## 监听事件

```javascript
mn.on('excerpt', function (d) {
  mn.api('/notes/batch-get', 
    { 
      method: 'POST',
      body: { noteIds: [d.noteid] } }
    ).then(function (r) { render(r); });
});
```

## 摘录事件筛选

面板关闭时用户进行摘录操作，MN 会先用 `mini` 模式把面板打开，再推送摘录事件，事件中的 `opened` 为 `true`。您可以在完成处理后调用 `mn.close()` 进行关闭。

如果只关心某一类摘录，可以用 `excerptClaim` 进行限制：

```json
{
  "addonid": "mn.vocab",
  "author": "MarginNote",
  "title": "Reading Vocabulary",
  "version": "0.13.1",
  "marginnote_version_min": "4.5.0",
  "immersiveOnly": true,
  "panel": "index.html",
  "icon": "vocab2.png",
  "panelWidth": 420,
  "panelMaxHeight": 620,
  "events": [
    "excerpt"
  ],
  "excerptClaim": {
    "hashtag": "#VocabPending",
    "configKey": "pendingTag"
  }
}
```

只有包含 `#VocabPending` 标签的新摘录事件才会触发该插件中的`excerpt`事件。

`configKey` 可选，写了之后此标签可以由模板配置覆盖，取值为模板里 `pluginConfigs[您的插件id]["pendingTag"]`。不写 `excerptClaim` 时，所有摘录行为均会唤起插件面板并触发`excerpt` 事件。

## 卡片菜单命令

`cardCommand` 不需要在 `events` 中声明。用户在卡片菜单里点了您声明过的命令之后：

```javascript
mn.on('cardCommand', function (d) {
  // d = { id: '命令id', noteid: '卡片id' }
});
```

## 注意事项

- 同一事件、同一张卡，1.5 秒内的重复事件会被丢弃
- 页面加载完成之前推来的事件会进入队列，加载完成后会统一发放
- 没有声明 `events` 的插件，无法收到事件
