`bottom` 与 `surfaces` 决定界面元素，写法见[工具与模式](/zh/template-bottom)与[顶部工作栏与浮窗](/zh/template-surfaces)。本篇的字段不产生界面元素，只改变进入场景界面之后的行为：`settings` 决定全局设置的预设值，`home` 决定首页类型，`review` 决定自动加入复习，`resume` 决定卡片状态的恢复方式，`coach` 控制引导条（场景界面上的一条提示）。

这些字段同样遵循[最小打包](/zh/basic-package)的覆盖规则：留空表示不接管。

`settings.global` 的生效时机与界面元素字段不同：只在进入场景界面期间临时生效，退出场景界面或换用其他场景模板即还原。

# 全局预设

`settings.global` 是一个对象，键为能力目录中的代号，值为该能力的预设值。能力目录由 MarginNote 提供。

```json template.json
{
  "settings": {
    "global": {
      "pref.titleFirstForNewCard": false,
      "pref.addToMap": true,
      "choice.insertPosition": 0,
      "choice.pageLayout": 0
    }
  }
}
```

每一项的取值方式按类别而定：开关类写入 `true` 或 `false`，不写入表示跟随；选项类写入具体档位，不写入表示跟随。能力目录中的动作类与面板类条目不作为预设使用。

<Note>
  键必须取自能力目录。目录中的条目按 action（动作）、toggle（开关）、choice（选项）、panel（面板）分组，完整清单见[代号词汇表](/zh/template-vocabulary)。
</Note>

## 临时生效与还原

预设值临时生效，退出后还原：

1. 进入场景界面时，MarginNote 先记下全局设置当时的真实值。
2. 把各项调整为模板写入的预设值。
3. 退出场景界面或换用其他场景模板时，把记下的值恢复为原值。

<Note>
  某一项的预设未生效时，先确认该项是否由学习集单独配置。学习集配置的内容始终优先，模板不改动该项。
</Note>

## 适合预设的项

以下各项在场景界面中使用频繁，写进 `settings.global` 可以省去手动调整：

- `pref.addToMap` 与 `pref.addBlankToMap`：摘录自动加入脑图、自动添加独立留白到脑图。
- `pref.lockactivenote` 与 `pref.lockfocusnote`：点击脑图时同步文档、点击文档时同步脑图。
- `pref.singleSideSketch` 与 `pref.docsketchontop`：单面手写、手写位于文字上层。
- `choice.noteFont` 与 `choice.baseFontSize`：卡片字体与基本字体尺寸。
- `choice.insertPosition`：脑图插入位置。写入按文档目录分组的档位时，摘录归入书籍目录中对应的章节。

<Note>
  以下项目不在预设范围内：只显示标题、点击查看全卡、在卡片中显示链接、脑图手写在卡片下层。书写背景由学习集单独配置。
</Note>

# 首页类型

`home` 决定进入场景界面时显示的首页。

| 值 | 含义 |
| --- | --- |
| 不写入 | 不接管，沿用全局默认 |
| `studyset` | 学习集主导 |
| `documents` | 文档首页 |

首页跟随场景界面，因此当前激活的场景模板决定首页的形态。系统场景模板均为学习集主导。

# 自动加入复习

`review` 控制回忆模态中的自动加入复习开关，以及自动进入复习的卡片范围。

## 自动加入复习开关

`review.autoAdd` 的取值：

| 值 | 含义 |
| --- | --- |
| 不写入 | 不接管，保持现状 |
| `offer` | 第一次在某个学习集中使用该模板时，询问一次是否打开 |
| `off` | 开关存在但默认关闭，且不询问 |

<Warning>
  该字段没有 `on` 取值。模板不得静默建立卡组或静默写入学习集。
</Warning>

开关出现的位置由 `bottom.modes` 决定：开关写进某一模态的 `tools` 时出现在该行上，写进 `overflow` 时收进收纳弹层。系统场景模板把开关放在回忆行上，具体位置由系统决定；`我的场景模板` 可以放在任意一行的任意位置。底部工具条上没有这个开关时，这段配置不起作用。

## 自动进入复习的卡片范围

`review.rule` 决定自动进入复习的卡片范围，字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `excludeToc` | `Bool?` | 目录与章节节点不进入。 |
| `excludeGroupChildren` | `Bool?` | 组内卡片不进入，即已经并入其他卡片的卡片不进入。 |
| `requireTitle` | `Bool?` | 没有标题的卡片不进入。 |
| `requireAddonValue` | `AddonValue?` | 插件元数据判定，条件成立才进入。 |

```json template.json
{
  "review": {
    "autoAdd": "offer",
    "rule": {
      "excludeToc": true,
      "excludeGroupChildren": true,
      "requireTitle": false,
      "requireAddonValue": {
        "addon": "mn.vocab",
        "key": "status",
        "equals": "done"
      }
    }
  }
}
```

`requireAddonValue` 的字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `addon` | `String` | 判定所依据的插件 id。 |
| `key` | `String` | 判定所依据的元数据键名。 |
| `equals` | `JSON?` | 期望的取值。 |

判定条件为：卡片的 `options["addon.<addon>"][key]` 与 `equals` 相等。插件通过写入元数据来标记卡片状态，模板据此决定是否放行。例如只让标记为 `done` 的卡片进入复习。

<Note>
  从外部导入的模板可能带有附加条件，只放行被特定标记的卡片。要修改需要改动模板本身。
</Note>

# 恢复与引导

`resume` 决定卡片状态在离开场景界面时的恢复方式，`coach` 控制引导条。

## 卡片状态的恢复

`resume.card` 的取值：

| 值 | 含义 |
| --- | --- |
| `silent` | 静默处理。 |
| `pending-only` | 仅处理待办项。 |
| `always` | 始终处理。 |

## 引导条

`coach` 的字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `enabled` | `Bool?` | 是否启用引导条。 |
| `mode` | `String?` | `teach` 为新手模式，含教学文案；`flow` 为过了新手期，无事时完全退场。 |
| `harvestBatch` | `Int?` | 引导条的采集批量。 |

# 完整示例

这份示例汇总了本篇的各组字段：首页为学习集主导；`settings.global` 预设 `pref.addToMap` 与 `pref.titleFirstForNewCard`；自动加入复习开关在第一次使用该模板的学习集中询问一次；目录与章节节点、已经并入其他卡片的卡片不进入复习；卡片状态按待办项恢复。`coach` 未写入。

```json template.json
{
  "id": "u-hello",
  "name": "你好世界",
  "home": "studyset",
  "settings": {
    "global": {
      "pref.addToMap": true,
      "pref.titleFirstForNewCard": false
    }
  },
  "review": {
    "autoAdd": "offer",
    "rule": {
      "excludeToc": true,
      "excludeGroupChildren": true
    }
  },
  "resume": {
    "card": "pending-only"
  }
}
```

写完配置后，可以按[校验与排错](/zh/template-validate)检查字段名与代号。
