场景界面底部有一条工具条，由若干**模态**组成。一个模态由一个标签页与一行工具组成：标签页负责切换，工具行收录这一页可以使用的工具。

模板接管这条工具条的方式是写出 `bottom.modes`。数组的每一项是一个模态，数组顺序即标签页的顺序；留空表示不接管（见[最小打包](/zh/basic-package)的覆盖规则），MarginNote 保持现状，这一点与模板的其余位置一致。

本文承接[最小打包](/zh/basic-package)，假定读者已经了解模板包的结构与覆盖规则。本文说明 `bottom` 的字段、`behavior` 的推导、工具行与收纳弹层的写法、笔盒与摘录颜色，以及旧字段 `toolbar.tabs` 的处理方式。

顶部的工作栏与右侧的浮窗另有配置，见[顶部工作栏与浮窗](/zh/template-surfaces)。本文只说明底部工具条的配置。

# 模态的结构

`bottom` 只有一个字段 `modes`，类型是模态数组。模态的全部字段如下：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `String` | 模态的标识。MarginNote 按标识记住这一模态上次使用的笔。 |
| `title` | `String?` | 标签页上的显示名。留空按 `behavior` 取本地化的 Read / Write / Recall。 |
| `icon` | `String?` | SF Symbol 名。留空按 `behavior` 取 `book` / `pencil.tip` / `brain.head.profile`。 |
| `behavior` | `String?` | 进入该模态时的行为，取 `read` / `write` / `recall`。留空由 `tools` 推导。 |
| `tools` | `[String]?` | 工具行的条目清单。留空表示不接管。 |
| `overflow` | `[String]?` | 只进入工具行末尾收纳弹层的条目。 |
| `entryTool` | `String?` | 进入该模态时激活的工具。 |
| `recall` | `Bool?` | 进入该模态时是否开启回忆会话。 |
| `inlineCount` | `Int?` | 摘录笔盒与手写笔盒共用的常显支数。旧字段。 |
| `inlineExcerpt` | `Int?` | 摘录笔盒常显的支数。 |
| `inlineInk` | `Int?` | 手写笔盒常显的支数。 |

`id` 与 `title` 决定标签页的显示方式。模态已命名但没有选择图标时，标签页上显示的是模态的名称；选择了图标就显示图标，名称只留在模板编辑器里。`icon` 的取值是 SF Symbol 名，在模板编辑器里可以按英文名搜索。

`inline*` 系列字段控制笔盒上常显的支数，超出的支数收进笔盒末尾的 `›`。留空时按窗口宽度自动决定，与现状相同。`inlineCount` 是摘录笔盒与手写笔盒共用一个数值的旧写法，只在 `inlineExcerpt` 与 `inlineInk` 都留空时生效。

`recall` 与 `behavior` 的 `recall` 表达同一件事：进入模态时是否开启回忆会话。`recall` 显式写出时以它为准。

# behavior 是推导出来的

`behavior` 的取值如下，每一项对应进入模态时 MarginNote 执行的一组动作。

- `read`：笔与摘录拾取器都关闭。
- `write`：启用笔与摘录拾取器。
- `recall`：进入回忆态。

留空时，MarginNote 按 `tools` 的内容推导：工具行上有回忆控件（`recall.*`）的模态算 `recall`；否则，行上直接出现笔盒的模态算 `write`；其余模态算 `read`。

这个推导是持续的，不是在保存时一次确定的。把一个书写模态的笔盒从工具行上移走，这一行就没有笔盒了，于是变成阅读模态；把笔盒加回去，书写模态恢复。未命名的模态，显示名随 `behavior` 一起变化；移走笔盒时，标签页上显示的名称也会随之更换。

<Note>
  `tools` 留空表示不接管，这一行的内容就是该行为下 MarginNote 当前的做法，推导结果也不会因为模板而改变。模板编辑器给这种模态标着 `默认内容`。
</Note>

## 进入时激活的工具

`entryTool` 决定进入模态时激活的工具，取值如下。

- `hand`：进入时激活手型工具。
- `last`：恢复这一模态上次使用的笔。

取值受下列限制。

- 工具行上没有笔时，只能取 `hand`。
- 笔折叠在笔组中时，进入时也不激活该笔。折叠的笔组代号是 `tool.penGroup` 与 `recall.handwrite`，笔在按钮之后，展开笔组后才会出现笔。

<Note>
  `entryTool` 与 `behavior` 相互独立：`behavior` 决定该模态启用的拾取器，`entryTool` 决定进入时激活的工具。模板编辑器目前仍写 `behavior`，MarginNote 读取配置时把两者换算之后使用。
</Note>

# 工具行与收纳弹层

`tools` 是一个字符串数组，数组顺序即工具行上从左到右的排列顺序。留空表示不接管，工具行显示该行为当前的默认内容。写出取值时完全以写出的内容为准，工具行上不会出现数组以外的条目。

`overflow` 收的是写态下放不下的条目。这些条目只进工具行末尾的收纳弹层，不占工具行的位置，也不会占用工具行的宽度。

常用代号如下。全部合法代号见[代号词汇表](/zh/template-vocabulary)。

| 类别 | 常用代号 | 界面上的位置 |
| --- | --- | --- |
| 读态开关 | `theme`、`titleLinks`、`blockSelect` | 主题、标题链接、块选择。 |
| 笔盒 | `tool.excerptBox`、`tool.inkBox` | 摘录笔盒、手写笔盒，各自占工具行一个位置。 |
| 墨迹代号 | `tool.ink.pen`、`tool.ink.marker`、`tool.ink.pencil`、`tool.ink.crayon` | 手写笔盒里可用的具体笔。 |
| 摘录代号 | `tool.excerpt.text`、`tool.excerpt.rect`、`tool.excerpt.lasso`、`tool.excerpt.highlight`、`tool.excerpt.blank` | 摘录笔盒里可用的具体摘录方式。 |
| 笔盒自带按钮 | `tool.excerptHand`、`tool.excerptConti`、`tool.hand`、`tool.lasso`、`tool.eraser`、`tool.textbox`、`tool.imagebox` | 笔盒组自带的按钮。 |
| 折叠的笔组 | `tool.penGroup`、`recall.handwrite` | 一个按钮，展开后是笔、套索、橡皮、撤销与完成的子行。 |
| 撤销与重做 | `undoRedo` | 写态固定按钮。 |
| 回忆控件 | `recall.settings`、`recall.reset`、`recall.hint`、`recall.level` | 回忆面板上的开关。 |
| 回忆态开关 | `pref.recall_single_peek`、`pref.recall_structured_mode`、`pref.recall_hint_use_afm`、`pref.recall_cover_all_excerpts`、`pref.recall_force_title_only` | 回忆模态下可加入工具行的开关。 |

墨迹与摘录代号描述的是笔盒里的具体条目；笔盒本身的代号是 `tool.excerptBox` 与 `tool.inkBox`，在工具行上各占一个位置。笔盒自带的那组按钮固定显示在笔盒组的末尾，位置不由 `tools` 的顺序决定。

<Warning>
  同一条目写多次没有意义。`tools` 是清单，不是集合，重复项在读入时按一次处理。
</Warning>

<Warning>
  代号写错时 MarginNote 不会报错，而是静默忽略该条目，表现为某一个按钮没有出现。排查办法见[校验与排错](/zh/template-validate)。
</Warning>

<Tip>
  `tools` 只写需要出现的条目，其余条目不会出现。覆盖规则在这里最容易误用：留空数组与不写这个字段含义不同，不写表示不接管，写空数组则把这一行清空。
</Tip>

# 笔盒与摘录颜色

模板可以自带下列内容，写在顶层：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `excerptTools` | `JSON?` | 模板自带的摘录工具集。 |
| `excerptColors` | `JSON?` | 模板自带的摘录颜色表，十六色。 |
| `canvasTools` | `JSON?` | 模板自带的手写笔盒。 |

三者都是 MarginNote 内部保存的原始数据；模板只是把 MarginNote 保存的那份原样复制过来，不做解释，也不做转换。留空表示继承，即沿用学习集或全局的配置；写出取值时，进入场景界面期间就使用这份配置，在场景界面里增删笔会写回这份配置，退出场景界面或更换模板后恢复为继承而来的配置。

`excerptColors` 的优先级如下：学习集配过颜色表时，一律采用学习集的颜色表，与模板的配置无关；模板的颜色表只在学习集没有配过时生效。

<Note>
  笔的颜色与粗细不在模板配置里直接设置。颜色与粗细在阅读时的笔盒面板与摘录设置面板里调整，调整结果直接写入这份模板配置。
</Note>

笔盒在工具行上占一个位置，笔盒组自带下列按钮：手写笔盒带套索、橡皮、手型、文本框、图片框，摘录笔盒带手型与连续摘录。这些按钮显示在笔盒组的末尾，不参与排序。

# chipStyle 的显示方式

`chipStyle` 是顶层的字符串字段，决定笔盒上每一支笔的显示方式，取值如下。

- `icon`：只显示图标。留空即这一档。
- `labeled`：以文字为主，右下角再放一个小图标，图标带着该工具的颜色。

这一档只影响未命名的笔；已命名的笔照旧显示名称，与 `chipStyle` 无关。想让某支笔只显示图标，把该笔的名称清空即可。

# 与旧字段的兼容

`toolbar.tabs` 是配置格式早期版本里的模态清单，schema 3 起由 `bottom.modes` 取代。

`bottom` 留空时的推导顺序如下：先看 `toolbar.tabs` 是否写出，写出取值时按照它推导模态；没有写出时使用 MarginNote 当前的读、写、忆模态。

使用 `toolbar.tabs` 的配置如下：

```json template.json
{
  "id": "u-legacy",
  "name": "旧写法",
  "toolbar": {
    "tabs": ["read", "write", "recall"]
  }
}
```

<Warning>
  新写的模板一律使用 `bottom.modes`。保留 `toolbar.tabs` 只为读懂已有的模板，不适合继续扩充。
</Warning>

# 完整示例

仓库的 `sdk/output/tools/starter/template/1-bottom.json` 是接管底部工具条的最小模板：

```json 1-bottom.json
{
  "id": "u-starter",
  "name": "起步",
  "minAppVersion": "4.5.0",
  "bottom": {
    "modes": [
      {
        "id": "collect",
        "title": "摘录",
        "behavior": "write",
        "entryTool": "last",
        "inlineExcerpt": 2,
        "tools": [
          "tool.excerptBox",
          "tool.excerptHand",
          "undoRedo",
          "theme"
        ]
      },
      {
        "id": "read",
        "title": "阅读",
        "behavior": "read",
        "tools": [
          "theme",
          "titleLinks"
        ]
      }
    ]
  }
}
```

逐部分说明如下。

- `minAppVersion`：模板用到 MarginNote 在某一版之后才提供的能力时声明它，导入时 MarginNote 版本不足会被拒绝。`bottom` 从 schema 3 起可用。
- `bottom.modes[0]`：摘录模态。`id` 是模板内部的标识；`title` 决定标签页上显示的名称；`behavior` 写明这是书写模态；`entryTool: "last"` 表示进入时恢复上次使用的笔；`inlineExcerpt` 固定摘录笔盒的常显支数。
- `tools` 的顺序即工具行上从左到右的排列顺序：摘录笔盒、摘录笔盒自带的手型按钮、撤销与重做、主题开关。
- `bottom.modes[1]`：阅读模态。`tools` 里没有任何笔盒或墨迹条目，因此这一行是纯读态开关。
- 阅读模态的 `tools` 没有写 `overflow`。留空即不接管收纳弹层。

模板里的 `id` 与 `name` 在[最小打包](/zh/basic-package)已经讲过。安装这份模板之后，进入场景界面，底部标签页从 MarginNote 默认的读、写、忆换成摘录与阅读。

配置的效果可以按下列步骤验证。

1. 进入摘录页，摘录笔盒常显两支笔，其余笔收在笔盒末尾的 `›` 中。
2. 把摘录笔盒（`tool.excerptBox`）从 `tools` 里删掉，这一页变成阅读页；把摘录笔盒加回 `tools`，书写模态恢复。

配置的修改立即生效，模板不需要保存。
