场景界面底部有一条工具条，由若干**模态**组成。一个模态由一个标签页与一行工具组成：标签页负责切换，工具行收录这一页可以使用的工具。

模板接管这条工具条的方式是写出 `bottom.modes`。数组的每一项是一个模态，数组顺序即标签页的顺序；留空表示不接管（见[最小打包](/zh/basic-package)的覆盖规则），MarginNote 保持现状，这一点与模板的其余位置一致。

顶部工作栏与右侧浮窗是另一套配置，写法见[顶部工作栏与浮窗](/zh/template-surfaces)。本文只讲底部工具条。

# 模态的结构

`bottom` 只有一个字段 `modes`，类型是模态数组。模态的字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `String` | 模态的标识。MarginNote 按标识记住这一模态上次使用的笔。 |
| `title` | `String?` | 标签页上的显示名。留空按 `behavior` 取本地化的 Read / Write / Recall。 |
| `icon` | `String?` | SF Symbol 名。留空按 `behavior` 取 `book` / `pencil.tip` / `brain.head.profile`。 |
| `behavior` | `String?` | 进入该模态时的行为，取 `read` / `write` / `recall`。旧写法，新写的模板改用 `entryTool` 与 `recall`。 |
| `tools` | `[String]?` | 工具行的条目清单。留空表示不接管。 |
| `overflow` | `[String]?` | 只进入工具行末尾收纳弹层的条目。 |
| `entryTool` | `String?` | 进入该模态时激活的工具。 |
| `recall` | `Bool?` | 进入该模态时是否开启回忆会话。 |
| `inlineCount` | `Int?` | 摘录笔盒与手写笔盒共用的常显支数。旧字段。 |
| `inlineExcerpt` | `Int?` | 摘录笔盒常显的支数。 |
| `inlineInk` | `Int?` | 手写笔盒常显的支数。 |

`id` 与 `title` 决定标签页的显示方式。模态已命名但没有选择图标时，标签页上显示的是模态的名称；选择了图标就显示图标，名称只留在模板编辑器里。`icon` 的取值是 SF Symbol 名，在模板编辑器里可以按英文名搜索。

`inline*` 系列字段控制笔盒上常显的支数，超出的笔收进笔盒末尾的 `›`。留空时按窗口宽度自动决定，与现状相同。`inlineCount` 是摘录笔盒与手写笔盒共用一个数值的旧写法，作为 `inlineExcerpt` 与 `inlineInk` 的兜底：某一项留空时，该项取 `inlineCount` 的值。

`recall` 与 `behavior` 的 `recall` 表达同一件事：进入模态时是否开启回忆会话。`recall` 显式写出时以 `recall` 为准。

# 读态、写态与忆态的推导

`behavior` 的取值与进入模态时的动作对应如下：

- `read`：笔与摘录拾取器都关闭。
- `write`：启用笔与摘录拾取器。
- `recall`：进入回忆态。

MarginNote 按工具行的内容推导三态：行上有回忆控件的模态判定为 `recall`；否则，行上直接出现笔盒的模态判定为 `write`；其余模态判定为 `read`。`behavior` 只用于推导 `recall` 与 `entryTool` 的缺省值，写出的 `read` 或 `write` 不改变读态与写态的结果。

该推导持续生效，配置改变后立即重新计算，不只在保存时计算一次。把书写模态的笔盒从工具行上移走，这一行没有笔盒，就变成阅读模态；把笔盒加回去，又恢复成书写模态。没有命名的模态，标签页上的显示名也跟着推导结果变化。

<Note>
  `tools` 留空时，工具行沿用 MarginNote 在该行为下的当前内容，推导结果不受模板影响。模板编辑器给这种模态标着 `默认内容`。
</Note>

## 进入时激活的工具

`entryTool` 决定进入模态时激活的工具：

- `hand`：激活手型工具。
- `last`：恢复这一模态上次使用的笔。

有以下限制：

- 工具行上没有笔时，模板编辑器只允许选择 `hand`。
- 笔折叠在笔组里时，进入时也不会激活该笔。折叠的笔组代号是 `tool.penGroup` 与 `recall.handwrite`，两者指向同一个按钮，展开后才能看到笔。

<Note>
  `entryTool` 决定进入时激活的工具，`recall` 决定进入时是否开启回忆会话。新写的模板请写 `entryTool` 与 `recall`；`behavior` 保留为兼容输入，只影响前两者的缺省值。
</Note>

# 工具行与收纳弹层

`tools` 是一个字符串数组，数组顺序即工具行上从左到右的排列顺序。留空表示不接管，工具行显示该行为当前的默认内容。写出取值时完全以写出的内容为准，工具行上不会出现数组以外的条目。

`overflow` 收的是该模态下放不下的条目。这些条目只进工具行末尾的收纳弹层，不占工具行的位置。

常用代号见下表，全部合法代号见[代号词汇表](/zh/template-vocabulary)。

| 类别 | 常用代号 | 界面上的位置 |
| --- | --- | --- |
| 读态开关 | `theme`、`titleLinks`、`blockSelect` | 主题、标题链接、块选择。 |
| 笔盒 | `tool.excerptBox`、`tool.inkBox` | 摘录笔盒、手写笔盒，各自占工具行一个位置。 |
| 墨迹代号 | `tool.ink.pen`、`tool.ink.marker`、`tool.ink.pencil`、`tool.ink.crayon` | 手写笔盒里可用的具体笔。 |
| 摘录代号 | `tool.excerpt.text`、`tool.excerpt.rect`、`tool.excerpt.lasso`、`tool.excerpt.highlight`、`tool.excerpt.blank` | 摘录笔盒里可用的具体摘录方式。 |
| 笔盒自带按钮 | `tool.excerptHand`、`tool.excerptConti`、`tool.hand`、`tool.lasso`、`tool.eraser`、`tool.textbox`、`tool.imagebox` | 笔盒组自带的按钮。 |
| 折叠的笔组 | `tool.penGroup`、`recall.handwrite` | 一个按钮，展开后是笔、套索、橡皮、撤销与完成的子行。 |
| 撤销与重做 | `undoRedo` | 写态固定按钮。 |
| 回忆控件 | `recall.settings`、`recall.reset`、`recall.hint`、`recall.level` | 回忆面板上的开关。 |
| 回忆态开关 | `pref.recall_single_peek`、`pref.recall_structured_mode`、`pref.recall_hint_use_afm`、`pref.recall_cover_all_excerpts`、`pref.recall_force_title_only` | 回忆模态下可加入工具行的开关。 |

墨迹与摘录代号是笔盒里的具体条目；笔盒本身的代号是 `tool.excerptBox` 与 `tool.inkBox`，在工具行上各占一个位置。笔盒自带的按钮需要写进 `tools`，写入后固定显示在笔盒组末尾，位置不由数组顺序决定：手写笔盒带套索、橡皮、手型、文本框、图片框，摘录笔盒带手型与连续摘录。

同一条目写多次只计一次。代号写错时 MarginNote 不会报错，而是静默忽略该条目，表现为某个按钮没有出现，排查办法见[校验与排错](/zh/template-validate)。

<Tip>
  不写 `tools` 表示不接管，写成空数组则是把这一行清空，两者不要混淆。
</Tip>

# 笔盒与摘录颜色

模板可以在顶层自带以下内容：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `excerptTools` | `JSON?` | 模板自带的摘录工具集。 |
| `excerptColors` | `JSON?` | 模板自带的摘录颜色表，十六色。 |
| `canvasTools` | `JSON?` | 模板自带的手写笔盒。 |

以上字段都是 MarginNote 内部保存的原始数据，模板只做原样复制，不做解释，也不做转换。

留空表示继承，沿用学习集或全局的配置。写出取值后，进入场景界面期间使用这份配置，在场景界面里增加或删除笔也会写回这份配置；退出场景界面或更换模板后，恢复为继承而来的配置。

`excerptColors` 有个例外：学习集配过颜色表时，一律采用学习集的，模板的颜色表只在学习集没配过时生效。

<Note>
  笔的颜色与粗细不在模板配置里直接设置，而在阅读时的笔盒面板与摘录设置面板里调整，调整结果直接写入这份模板配置。
</Note>

# chipStyle 的显示方式

`chipStyle` 是顶层的字符串字段，决定笔盒上每一支笔的显示方式：

- `icon`：只显示图标。留空即这一档。
- `labeled`：以文字为主，右下角再放一个小图标，图标带着该工具的颜色。

该字段只影响未命名的笔；已命名的笔照旧显示名称。想让某支笔只显示图标，清空该笔的名称即可。

# 与旧字段的兼容

`toolbar.tabs` 是配置格式早期版本里的模态清单，schema 3 起由 `bottom.modes` 取代。`bottom` 留空时，MarginNote 先检查 `toolbar.tabs` 是否写入，写入时按该清单推导模态，未写入则使用当前的读态、写态与忆态。

旧写法如下：

```json template.json
{
  "id": "u-legacy",
  "name": "旧写法",
  "toolbar": {
    "tabs": ["read", "write", "recall"]
  }
}
```

<Warning>
  新写的模板一律使用 `bottom.modes`。保留 `toolbar.tabs` 只为读懂已有的模板，不适合继续扩充。
</Warning>

# 完整示例

下面是接管底部工具条的最小模板：

```json template.json
{
  "id": "u-starter",
  "name": "起步",
  "minAppVersion": "4.5.0",
  "bottom": {
    "modes": [
      {
        "id": "collect",
        "title": "摘录",
        "behavior": "write",
        "entryTool": "last",
        "inlineExcerpt": 2,
        "tools": [
          "tool.excerptBox",
          "tool.excerptHand",
          "undoRedo",
          "theme"
        ]
      },
      {
        "id": "read",
        "title": "阅读",
        "behavior": "read",
        "tools": [
          "theme",
          "titleLinks"
        ]
      }
    ]
  }
}
```

- `minAppVersion`：模板用到 MarginNote 在某一版本之后才提供的能力时声明该字段，导入时 MarginNote 版本不足会被拒绝。`bottom` 从 schema 3 起可用。
- `bottom.modes[0]`：摘录模态。`id` 是模板内部的标识；`title` 决定标签页上显示的名称；`behavior` 写明这是书写模态；`entryTool: "last"` 表示进入时恢复上次使用的笔；`inlineExcerpt` 固定摘录笔盒的常显支数。
- `tools` 的顺序即工具行上从左到右的排列顺序：摘录笔盒、摘录笔盒自带的手型按钮、撤销与重做、主题开关。
- `bottom.modes[1]`：阅读模态。`tools` 里没有任何笔盒或墨迹条目，因此这一行是纯读态开关。
- 阅读模态的 `tools` 没有写 `overflow`。留空即不接管收纳弹层。

安装这份模板后进入场景界面，底部标签页从 MarginNote 默认的读态、写态、忆态换成摘录与阅读。验证方式如下：

1. 进入摘录页，摘录笔盒常显两支笔，其余笔收在笔盒末尾的 `›` 中。
2. 把摘录笔盒（`tool.excerptBox`）从 `tools` 里删掉，这一页变成阅读页；把摘录笔盒加回 `tools`，书写模态恢复。

配置的修改立即生效，模板不需要保存。
