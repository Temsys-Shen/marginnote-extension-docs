title: "数据交互"
---

插件的面板可以与 Marginnote 进行通信来获取信息、改写信息以及执行操作。

# 请求方式

请求方式分为 `GET` 和 `POST`，前者可以直接请求，后者需显示指定 method，例如：

<CodeGroup>

```javascript GET
const state = await mn.api('/ui-state');
const topicid = state.state.topicid;
```

```javascript POST
await mn.api('/notes/addon-values', {
  method: 'POST',
  body: { noteIds: [noteid], values: { status: 'done' } }
});
```

</CodeGroup>

# 可用接口

插件可调用的接口由 Marginnote CLI 所有可用接口裁剪而来，所有插件可用的接口见 `API 参考` 。

`/bridge/v1` 之外，页面还能访问面板本地的其他路径，包括读取插件包内的文件、读取图片与调整控制面板尺寸。这些路径不经过 MarginNote，也不受白名单限制，写法见[路径系统](/zh/paths)。

# 错误处理

`mn.api` 不使用 reject 表示失败，而是把错误对象作为正常的响应体返回。这意味着无法使用 `try...catch` 捕获异常的请求。

下面是一个错误的例子：

```json
{
  "error": {
    "code": "IN_PROCESS_NOT_ALLOWED",
    "message": "该接口不在网页面板的白名单上。",
    "retryable": false
  }
}
```

判断一次调用是否成功，应先检查响应中是否包含 `error` 字段，再结合具体的请求进行判断：

```javascript
const r = await mn.api('/notes/' + noteid + '/edits', {
  method: 'POST',
  body: { ops: [{ op: 'setTitle', text: '新的标题' }] }
});

if (r.error) {
  mn.log(r.error.code, r.error.message);
} else if (r.persisted) {
  mn.log('已写入并核对通过');
}
```

# 返回值非 JSON 的接口

`mn.api(path, opts)` 等效于在路径`/bridge/v1`上的 fetch 行为，并**返回JSON**：

```javascript
fetch('/bridge/v1' + path, opts).then(r => r.json())
```

接口返回的内容不是 JSON 时，调用会在解析阶段抛出 `SyntaxError`，无法获取原始内容。这类接口应改用 `fetch`进行调用。例如：

- `GET /guide` 返回 Markdown 正文。
- `GET /notes/{noteid}/render` 返回卡片长图或 PDF。
- `GET /documents/{bookmd5}/pages/{index}/content/{contentId}` 返回图片。
- `GET /bundles/{bundleId}/files` 带 `path` 时返回该文件的原始字节。

按响应内容的类型选择读取方式：

```javascript
// 响应的内容是 Markdown
const text = await (await fetch('/bridge/v1/guide')).text();

// 响应的内容是字节流
const shot = await fetch('/bridge/v1/notes/' + noteid + '/render?format=png&width=880');
const blob = await shot.blob();
```

关于路径`/bridge/v1` 的行为以及其他可用路径，参见 [路径系统](/zh/paths) 。

# 完整示例

以摘录制卡（如单词卡）为例Ï，一个通常的处理是：<br />插件获取当前上下文的信息后，据此取出卡片数据中的相关信息，最后根据实际需求为处理完成的卡片进行标记。

```javascript
mn.on('excerpt', async d => {
  // 一、获取当前界面状态，得到学习集与聚焦的卡片
  const ui = await mn.api('/ui-state');
  const topicid = ui.state.topicid;

  // 二、获取该卡片的标题、正文、标签与插件字段
  const got = await mn.api('/notes/batch-get', {
    method: 'POST',
    body: { noteIds: [d.noteid], addons: ['mn.hello'] }
  });
  const card = got.items[0];
  if (!card.found) return;

  // 处理数据

  // 三、把结果写回本插件自己的字段
  await mn.api('/notes/addon-values', {
    method: 'POST',
    body: { noteIds: [d.noteid], values: { status: 'done', topicid } }
  });
});
```
