title: "网络请求限制"
---

# 连接范围

插件面板允许 `https:` 与 `wss:` 连接，也允许本机回环地址上的 HTTP 与 WebSocket 连接。

本机连接来源仅限以下地址，端口范围不受限制：

- `http://localhost:<端口>`
- `http://127.0.0.1:<端口>`
- `ws://localhost:<端口>`
- `ws://127.0.0.1:<端口>`

公网 `http:` 与公网 `ws:` 连接仍然拒绝。`0.0.0.0`、`::1`、局域网 IP 与自定义主机名不在允许列表内。

# 跨域请求

面板的地址是 `mnpanel://panel`，在处理跨域请求配置 CORS 时可能会用到此地址。

```text
Access-Control-Allow-Origin: mnpanel://panel
```

# 页面跳转

- 用户点击 `http:` 与 `https:` 链接时，地址交给系统浏览器打开，面板不会进行跳转。
- 页面自行修改 `location`、提交表单都不会生效。要向服务端发送数据时，需用 `fetch`。

# 内容安全策略

面板的每条响应都带有内容安全策略（CSP），页面可以加载的资源与可以发起的连接由该策略限定。

- 加载资源：允许面板同源资源、`mnpanel:`、`https:` 与 `localhost`、`127.0.0.1` 的 HTTP 资源。脚本、样式、图片、字体、音视频与 iframe 均受此规则约束。
- 发起连接：允许面板同源资源、`mnpanel:`、`https:`、`wss:`、本机 HTTP、本机 WebSocket、`data:` 与 `blob:`。
- 补充来源：图片与音视频额外允许 `data:` 与 `blob:`；字体额外允许 `data:`。
- 禁用项：`object` 标签、`<base>` 标签与表单提交。

策略逐条限定来源，完整取值如下：

```text
default-src 'self' mnpanel: https: http://localhost:* http://127.0.0.1:*
connect-src 'self' mnpanel: https: wss: http://localhost:* http://127.0.0.1:* ws://localhost:* ws://127.0.0.1:* data: blob:
script-src 'self' mnpanel: https: http://localhost:* http://127.0.0.1:* 'unsafe-inline' 'unsafe-eval'
style-src 'self' mnpanel: https: http://localhost:* http://127.0.0.1:* 'unsafe-inline'
img-src 'self' mnpanel: https: http://localhost:* http://127.0.0.1:* data: blob:
media-src 'self' mnpanel: https: http://localhost:* http://127.0.0.1:* data: blob:
font-src 'self' mnpanel: https: http://localhost:* http://127.0.0.1:* data:
frame-src 'self' mnpanel: https: http://localhost:* http://127.0.0.1:*
object-src 'none'
base-uri 'none'
form-action 'none'
```
