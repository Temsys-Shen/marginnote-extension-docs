正如 [数据交互](/zh/data-interact) 一节所述，面板与 MN 的数据交互是使用`mn.api `实现的，而该方法又等效在`/bridge/v1/` 路径上的 fetch 行为。同样地，与 MN 的其他的交互方式也可通过路径系统实现。

# 路径一览

| 路径 | 方法 | 用途 | 失败响应 |
| --- | --- | --- | --- |
| `/`、`/index.html` | GET | 面板的页面文件 | `500 PANEL_FILE_MISSING` |
| `/bridge/v1/…` | GET \| POST | MarginNote API 接口 | `403 IN_PROCESS_NOT_ALLOWED` |
| `/addon/<名称>` | POST | 请求 `main.js `上定义的方法 | `500 ADDON_CALL_FAILED`、`500 ADDON_BAD_RESULT`、`500 ADDON_THREW` |
| `/media/<键>` | GET | 返回 `putMedia` 存入的原始字节 | `404 NO_MEDIA` |
| `/ai/run-task` | POST | 调用模板声明的 AI 任务 | `403 ADDON_NOT_ACTIVE`、`501 AI_UNAVAILABLE`、`500 AI_BAD_RESULT` |
| `/pkg/<路径>` | GET | **返回插件包内的文件** | `404 NO_PKG_FILE` |
| `/ui/*` | GET | 控制面板的尺寸、形态与位置 | `{"ok":true}` |
| 其它 | — | — | `404 NOT_FOUND` |

# `window.mn 成员方法对应路径`

| 调用 | 路径 |
| --- | --- |
| `mn.api(path, opts)` | `/bridge/v1`\+ `path` |
| `mn.call(name, data)` | `/addon/<name>` |
| `mn.ai(noteid, taskId, params)` | `/ai/run-task` |
| `mn.height`、`mn.size`、`mn.mode`、`mn.close`、`mn.reload` | `/ui/` 下的对应路径 |
| `mn.log(...)` | `/ui/log?level=log` |

# 使用插件包内文件

使用`/pkg/` 引用插件包根目录的文件，例如资源数据、CSS、图片等。

例如下面插件目录：

<Tree>
  <Tree.Folder name="mn-addon">
    <Tree.Folder name="assets" defaultOpen>
      <Tree.File name="style.css" />
    </Tree.Folder>
    <Tree.Folder name="scripts" defaultOpen>
      <Tree.File name="model.js" />
    </Tree.Folder>
    <Tree.File name="index.html" />
    <Tree.File name="mnaddon.json" />
  </Tree.Folder>
</Tree>

可以如下引用：

```html
<link rel="stylesheet" href="/pkg/assets/style.css" />
<script src="/pkg/scripts/model.js"></script>
```

<Warning>
  ".."、绝对路径、包外路径均无法使用
</Warning>

# 媒体资源

使用`putMedia` 将媒体数据传输给面板后（见[面板之外 › 媒体数据](/zh/jsaddon#%E5%AA%92%E4%BD%93%E6%95%B0%E6%8D%AE)），面板可以用 `/media/<key>` 取得该媒体的原始字节。

# 请求 `main.js `上定义的方法

 `mn.call(name, data)` 等效于：

- POST `/addon/<name>`
- Request Body: `data`(JSON Format)

 参见[面板之外](/zh/jsaddon)

# 执行 AI 任务

`mn.ai(noteid, taskId, params)` 等效于：

- POST  `/ai/run-task` 
- Request Body:`{noteid, taskId, params}`

参见 [使用 MN 内置 AI](/zh/use-inner-ai) 

# UI 相关

| 路径 | 对应调用 |
| --- | --- |
| `/ui/height?h=<h>` | `mn.height(h)` |
| `/ui/size?w=<w>&h=<h>` | `mn.size(w, h)` |
| `/ui/mode?m=<mode>` | `mn.mode('workspace' \| 'mini')` |
| `/ui/move?dx=<dx>&dy=<dy>&phase=<begin\|end>` | — |
| `/ui/close` | `mn.close()` |
| `/ui/reload` | `mn.reload()` |

参见 [UI 控制](/zh/ui)
