模板的每一个名册位置都有一份封闭清单。只有清单中的代号会被宿主采纳，其余代号被静默忽略，宿主不会报错。

本文按摆放位置列出全部合法代号，供查阅。写模板时如果某颗按钮没有出现，先到本文确认代号拼写与位置是否正确。

# 使用方式

代号能否生效取决于两个条件：代号在清单内，且放在该清单对应的位置。两个条件缺一不可。

`act.crop` 是一个具体的例子。该代号在顶部导航清单内，因此能放进 `surfaces.nav`；放进 `bottom.modes[].tools` 则被静默忽略，因为该位置不收这条代号。

<Warning>
  代号写错与代号放错位置都不会报错。校验办法见[校验与排错](/zh/template-validate)。
</Warning>

# 能力目录

能力目录中的代号可以放进两处：`bottom.modes[].overflow`（收进 `更多` 弹层）与 `settings.global`（预设拨到哪一档）。

目录由宿主在运行时生成，它是权威来源。编辑器中的备用清单只在尚未进入过场景界面时代替目录生效。

`domain` 列给出作用对象，它决定该条目归顶部还是归底部。

# 插件代号

插件贡献的代号由插件 id 动态拼出，不在静态清单内，因此校验器只检查形状，不检查具体取值。

```text
bottom.modes[].tools    addon.<插件id>.<名字>
selectionMenu.*         addon.<插件id>.<命令id>:
```

末尾的冒号不可省略。详见[接入插件](/zh/template-plugins)与[卡片与摘录菜单](/zh/template-menu)。

# 笔盒中的动态引用

笔盒里按序号引用的工具属于动态引用，同样不在静态清单内：

```text
excerpt:<序号>
sketch:<序号>
undo:<序号>
```

校验器会跳过这三类代号的检查。
