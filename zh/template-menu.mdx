场景界面里的弹出菜单由模板顶层的 `selectionMenu` 决定：插件负责命令本身，模板负责菜单上出现的条目。本篇承接[顶部工作栏与浮窗](/zh/template-surfaces)，说明 `selectionMenu` 的字段与作用位置、菜单项代号、插件命令项，以及选中文本菜单上的划线快捷项。阅读之前需要掌握场景界面、MarginNote、模板编辑器与模板的覆盖规则。

`selectionMenu` 是一个对象，对象中的每个字段是一张清单。每张清单是一个字符串数组，数组里的每个元素是一个动作代号。清单列出的是该菜单允许出现的最大范围。

字段整体留空表示不接管（见[最小打包](/zh/basic-package)的覆盖规则），菜单沿用 `收藏管理器` 里的收藏。

模板编辑器把这些清单集中在 `卡片与摘录菜单` 这一页。该页顶部的搜索框同时过滤菜单清单、卡片多选工具栏与划线快捷项，只保留名称命中的条目，没有条目命中时给出提示，清空搜索框即恢复全部。搜索框下方的折叠段写着 `菜单设置说明`，内容与下文的最大集语义一节一致。

# 清单与作用位置

`SelectionMenu` 的字段如下。

| 字段 | 类型 | 作用位置 |
| --- | --- | --- |
| `cards` | `[String]?` | 卡片菜单。在脑图与大纲中共用一张清单。 |
| `documents` | `[String]?` | 文档上的卡片菜单。在 PDF、EPub、视频等界面上共用一张清单。 |
| `text` | `[String]?` | 选中文本时弹出的菜单。在 PDF 与 EPub 上共用一张清单。 |
| `PDFReader` | `[String]?` | 按 MarginNote 界面细分的写法，仅 PDF 阅读器生效。 |
| `EPubReader` | `[String]?` | 按 MarginNote 界面细分的写法，仅 EPub 阅读器生效。 |
| `MindMap` | `[String]?` | 按 MarginNote 界面细分的写法，仅脑图生效。 |
| `Digest` | `[String]?` | 按 MarginNote 界面细分的写法，仅 Digest 界面生效。 |

模板编辑器中呈现的清单如下：卡片菜单、文档上的卡片菜单、选中文本菜单。表中其余字段是按 MarginNote 界面细分的写法，用于覆盖特定界面。

<Note>
  `text` 的取值范围与其他清单不同。该清单给出的是菜单上允许出现的最大范围：清单之外的动作收进 `More` 子菜单，仍然可以使用；其余清单之外的条目不出现。
</Note>

`text` 留空表示沿用 `收藏管理器` 里收在折叠集中的条目，与其余清单的留空含义一致。

# 最大集语义

清单里列出的条目限定的是最大范围，与逐条打开的开关不同。菜单真正弹出时，MarginNote 还会按当时实际可用的操作过滤一遍。因此在同一张清单里同时写出删除卡片与删除摘录，菜单上仍然只出现其中实际可用的动作。

清单的使用还有以下规则。

- 未接管时，菜单显示当前的收藏；一经勾选即视为接管，此后这张菜单的组成由模板决定。
- 场景界面下这些菜单只以场景模板为准：在卡片菜单上添加条目、在选中文本菜单的 `More` 里打开定制入口、以及长按菜单项收藏或取消收藏，修改的都是模板里的这几份清单，不再写入学习集或全局设置。传统界面不受影响。

<Note>
  摘录完成后，场景界面上会浮出一条结果浮条，浮条上的 `摘录操作` 按钮打开摘录菜单。该浮条由 `surfaces.excerptResultBar` 控制，参见[顶部工作栏与浮窗](/zh/template-surfaces)。
</Note>

## 候选项

候选项是模板编辑器中可供勾选的条目，由默认收藏与该菜单实际出现过的条目组成。清单在模板编辑器中列出的条目取自候选项，因此刚接管时清单可能为空，模板编辑器会提示需要进入场景界面打开一次对应的菜单才会登记。菜单在此后出现过的新条目同样会补进候选项。

## 编辑顺序与恢复默认

每份清单一行一个功能，已勾选的条目排在前面。清单标题右侧提供 `编辑顺序` 与 `恢复默认` 按钮。`编辑顺序` 打开一个可以拖动排序、增删条目的界面，只在该清单已有候选项时出现；`恢复默认` 在接管之后才出现。

<Tip>
  系统场景模板下这几份清单也能在模板编辑器中直接修改，改动只存在当前设备上，不随模板分发给别人。
</Tip>

# 菜单项代号

清单里的每个元素是一个动作代号。内置动作的代号取自固定清单，完整清单见[代号词汇表](/zh/template-vocabulary)。本文只取其中几项作为示例。

**部分代号末尾带冒号，冒号是代号本身的一部分，写入时不能省略。** 也有不带冒号的代号，带冒号与不带冒号的写法都合法。

```json template.json
{
  "id": "u-hello",
  "name": "你好世界",
  "selectionMenu": {
    "cards": [
      "noteHighlight:",
      "commentNote"
    ],
    "documents": [
      "sendHighlight:",
      "noteHighlight:"
    ]
  }
}
```

数组中的顺序即菜单中的排列顺序。

同一个功能在不同菜单里的代号可能不同，写入时以目标菜单的清单为准。

<Warning>
  代号拼错时 MarginNote 不报错，该条目被静默忽略。模板校验脚本（见[校验与排错](/zh/template-validate)）检查字段名与各份清单的条目，`selectionMenu` 中的代号不在检查范围内。
</Warning>

# 插件命令项

插件贡献的命令使用另一种格式的代号：`addon.<插件id>.<命令id>:`。末尾的冒号同样不能省略。

这类条目需要插件与模板共同写出：插件在 `mnaddon.json` 的 `cardCommands` 中声明这条命令，模板在对应的清单中写出这个代号；声明与写出都完成之后，该条目才会出现在菜单上。命令的声明写法与接收方式见[卡片与摘录菜单命令](/zh/menu-commands)。

插件本身需先列入模板顶层的 `plugins` 白名单，未列入时不存在。白名单的写法见[接入插件](/zh/template-plugins)。

```json mnaddon.json
{
  "addonid": "mn.starter",
  "title": "起步",
  "version": "0.3.0",
  "marginnote_version_min": "4.5.0",
  "panel": "index.html",
  "cardCommands": [
    {
      "id": "annotate",
      "title": { "zh-Hans": "添加批注", "en": "add a comment" }
    }
  ]
}
```

```json template.json
{
  "id": "u-hello",
  "name": "你好世界",
  "plugins": ["mn.starter"],
  "selectionMenu": {
    "cards": [
      "noteHighlight:",
      "commentNote",
      "addon.mn.starter.annotate:"
    ],
    "documents": [
      "sendHighlight:",
      "noteHighlight:",
      "addon.mn.starter.annotate:"
    ]
  }
}
```

<Note>
  菜单上找不到这一项时，逐一核对下表即可定位原因。
</Note>

| 现象 | 排查方向 |
| --- | --- |
| 菜单上没有这一项 | 插件是否在 `mnaddon.json` 的 `cardCommands` 中声明了该命令。 |
| 声明之后仍不出现 | 插件是否列进了模板顶层的 `plugins` 白名单。 |
| 卡片菜单上出现，文档菜单上没有 | 模板是否在 `documents` 中也写出了同一个代号。 |
| 在任何清单里都不生效 | 代号末尾的冒号是否漏写。 |
| 同一条命令在卡片菜单与文档菜单里表现不同 | 命令在 `mnaddon.json` 中声明的 `when` 条件是否在这张菜单所对应的卡片上成立。 |

# 划线快捷项

选中文本时弹出的菜单上有一排快捷按钮，点击其中一个按钮，选中的文字即按预定的设置摘录成卡片。这排按钮由模板顶层的 `excerptShortcuts` 定义，该字段不在 `selectionMenu` 之内，最多容纳 8 个按钮。

字段的值是对象数组，每个按钮是一个对象。可确证的字段如下。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `title` | `String` | 按钮上显示的文字。 |
| `hashtag` | `String` | 该项摘录出的卡片所带的标签。 |
| `color_index` | `Int` | 该项使用的颜色序号。 |
| `ai_addon` | `String` | 该项的 AI 处理交给的插件 id，对应模板编辑器里的 `AI 交给：……`。取值写法见[AI 任务](/zh/template-ai)。 |

`text` 清单决定每个快捷按钮在条上占用的槽位：清单中列出某个槽位条目，该槽位才会真正显示在条上。槽位条目的完整清单见[代号词汇表](/zh/template-vocabulary)。

```json template.json
{
  "id": "u-hello",
  "name": "你好世界",
  "excerptShortcuts": [
    { "title": "抓取一句", "hashtag": "", "color_index": 0, "ai_addon": "" },
    { "title": "标记标题", "hashtag": "#重点", "color_index": 1, "ai_addon": "" }
  ],
  "selectionMenu": {
    "text": [
      "noteHighlight:"
    ]
  }
}
```

`excerptShortcuts` 留空表示跟随当前生效的快捷项设置：学习集中保存过摘录设置时跟随学习集，否则跟随全局。写出取值之后，场景界面期间使用模板中登记的快捷项，在场景界面里新建、编辑、删除快捷项都写回该字段，每个模板各自独立。

模板编辑器中这一块的标题写作 `划线快捷项（选中文本菜单上的快捷按钮，最多 8 个）`，`当前生效` 一行标明正在使用的是哪一套设置。接管之后出现 `用当前这套覆盖场景模板里的` 按钮，同时提供改回跟随学习集或全局的入口，用于放弃接管。每一项右侧有 `编辑` 与 `删除` 按钮，未满上限时底部出现新建快捷项的入口。装有会接收 AI 任务的插件时，每一项下方还有 `AI 交给：……` 菜单。还没有快捷项时模板编辑器给出提示；从场景界面之外打开模板编辑器读不到当前生效的快捷项，同样给出提示。

系统场景模板下这一整块只能查看，复制为 `我的场景模板` 之后才能修改。

# 与多选工具栏的关系

卡片被多选时，底部出现的工具栏由 `surfaces.multiSelect` 控制，与本篇的清单分属不同字段，参见[顶部工作栏与浮窗](/zh/template-surfaces)。

# 完整示例

下面这份模板接管卡片菜单、文档上的卡片菜单、选中文本菜单与划线快捷项，并列入一条插件命令。

```json template.json
{
  "id": "u-starter",
  "name": "起步",
  "minAppVersion": "4.5.0",
  "plugins": ["mn.starter"],
  "selectionMenu": {
    "cards": [
      "noteHighlight:",
      "commentNote",
      "addon.mn.starter.annotate:"
    ],
    "documents": [
      "sendHighlight:",
      "noteHighlight:",
      "addon.mn.starter.annotate:"
    ],
    "text": [
      "noteHighlight:"
    ]
  },
  "excerptShortcuts": [
    { "title": "抓取一句", "hashtag": "", "color_index": 0, "ai_addon": "" },
    { "title": "标记标题", "hashtag": "#重点", "color_index": 1, "ai_addon": "" }
  ]
}
```
