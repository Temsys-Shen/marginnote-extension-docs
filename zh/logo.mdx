# 图标要求

图标文件需要是 PNG 图片，尺寸建议采用 64×64 ，但也可以根据实际需求采用更大或更小的图标。

MN 绘制图标时会将图标当作 alpha 蒙版，只保留形状轮廓，用界面颜色绘制成单色。因此图标需要保证图形以外的区域全部透明。

# 风格指南

### 1. 聚焦核心剪影

单色渲染完全依赖外轮廓传达语义。设计时应提炼对象最具辨识度的特征，避免冗余的修饰性细节。小尺寸下，复杂的线条容易黏连失真，越清晰简洁的剪影越具有可读性。

### 2. 利用负空间构图

由于不支持多色分层，图标内部的层次、细节与分隔必须通过透明的负空间（镂空）来呈现。镂空缝隙需保持足够间距（建议不小于 2 像素），防止在小尺寸渲染时因抗锯齿而闭合。

### 3. 避免半透明与模糊

图形内容应保持 100% 不透明度。虽然 Alpha 通道支持透明度阶调，但低不透明度像素在与界面前景色混合后容易发虚或显得脏浊。明确的硬边缘才能确保在各类底色上呈现锐利清晰的质感。

### 4. 平衡视觉量感

图标应在 64×64 像素的画布中居中对齐，并保持统一的视觉重量：

- **留白规范**：画布四周建议保留 4-6 像素的安全边距，避免图形撑满画布带来压迫感。
- **光学对齐**：当图标形态不对称时，应依据视觉中心而非几何中心对齐；方形图标需适度内缩，长条形或圆形可适当扩展，以保证并排展示时体量一致。

### 5. 规范笔画与转角

- **笔画宽度**：描边与线条建议维持在 3～5 像素，避免使用细于 3 像素的线条。
- **转角特征**：线条端点与折角宜采用微圆角处理，使视觉质感平滑现代，并与原生界面规范保持一致。

# 配置描述文件

建议在 `mnaddon.json` 中用 `icon` 字段指定图标文件：

```json mnaddon.json highlight={8} focus={8}
{
  "addonid": "mn.hello",
  "title": "你好世界",
  "version": "0.1.0",
  "author": "我",
  "marginnote_version_min": "4.5.0",
  "panel": "index.html",
  "icon": "hello.png",
  "events": ["excerpt", "comments"]
}
```

MN 将按如下顺序采用图标

1. 采用 `icon` 字段中配置的图标。
2. `icon`字段未配置或无效时，采用与 `addonid` 末段同名的 PNG图标。 例如，`addonid` 为 `mn.hello` 时，采用 `hello.png`。
3. 仍未找到时，使用插件包内唯一的 PNG图标。

如果上述流程均失败，插件将无图标。

<Note>
  `icon`字段需相对插件包的根目录书写。路径中出现 `..` 或者使用绝对路径时，MN 会拒绝导入这个插件包。
</Note>
